# SkillPath 🚀

**SkillPath** is a collaborative web development project focused on building a website to showcase skills, projects, achievements, and personal growth.

## 📌 About the Project

SkillPath aims to provide a simple and user-friendly platform for presenting personal and professional information. This project is being developed collaboratively, allowing team members to contribute to different parts of the website while learning and improving their web development skills.

## ✨ Planned Features

* 🏠 Home page
* 👤 About section
* 💻 Skills showcase
* 🚀 Projects portfolio
* 🏆 Achievements section
* 📩 Contact section
* 📱 Responsive design

## Run locally

Because the app uses ES modules, serve the folder from a local static server instead of opening `index.html` directly:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Included

- Known-career profile flow with skill-gap analysis
- 10-question career discovery assessment
- Rule-based recommendations across 8 career paths
- Prerequisite-aware roadmap ordering
- Resources and capstone project suggestions
- Progress tracking persisted in `localStorage`
- Responsive layout for desktop and mobile

## 🤝 Contribution Guidelines

We welcome contributions from all team members.

1. Clone the repository.
2. Create a separate branch for your feature or task.
3. Make your changes and commit them with meaningful commit messages.
4. Push your branch to GitHub.
5. Open a pull request for review before merging into `main`.

Please avoid making direct changes to the `main` branch.
